# Java Servlet Assignment

## Description
This project is a simple Java web application using a Servlet that displays
a "Hello" message followed by my name. The application is deployed on Apache Tomcat.

## Technologies Used
- Java JDK 8
- Apache Tomcat 9.0.115
- IntelliJ IDEA Community Edition
- Maven
- Windows 11

## Steps Followed

1. Installed Apache Tomcat and verified it using a web browser.
2. Created a Maven Java project in IntelliJ.
3. Implemented a Servlet using `@WebServlet`.
4. Compiled the project using Maven to generate a WAR file.
5. Deployed the WAR file manually to Tomcat.
6. Created an HTML page containing a link to the servlet.
7. Tested the application from a web browser.
